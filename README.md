# Zine 3D

지네를 움직여 몸을 늘리고 기록을 만드는 3D 아케이드 게임의 WebGL 배포본입니다.

## 플레이

**https://ghtnql.github.io/Zine3D/**

- PC: 화면의 방향 버튼 또는 게임 내 조작 UI 사용
- iPhone/Android: Safari나 Chrome에서 가로 화면 권장
- iPhone에서는 Safari의 공유 메뉴에서 **홈 화면에 추가**를 선택하면 앱처럼 실행할 수 있습니다.

이 저장소에는 GitHub Pages 배포에 필요한 빌드 결과물만 포함되어 있습니다. Unity 원본 프로젝트와 서명 파일은 공개하지 않습니다.
